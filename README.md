# MobileDU
Repositório oficial da tese de doutorado “Diretrizes para o Desenvolvimento de Aplicações Móveis Voltadas para o Desenho Universal: a Biblioteca MobileDU”. Contém documentos, scripts, planilhas e o código-fonte da MobileDU, disponibilizados para fins acadêmicos e para desenvolvedores interessados em utilizar e evoluir o projeto.
